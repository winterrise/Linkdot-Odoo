# Linkdot-Odoo

Linkdot 的 Odoo 18 通用模組（不綁特定客戶；客戶特有的值放各自資料庫的設定）。
依 CorPaaS 夥伴開發手冊：模組資料夾直接放在 repo 根目錄；分支 `dev-18.0`（開發）、`18.0`（穩定）、`feature/<主題>`。

| 模組 | 用途 |
|---|---|
| `linkdot_health_check` | 員工健康檢查（勞工健康保護規則：體格檢查、一般／特殊健檢、異常追蹤） |
| `linkdot_auth_oauth_email` | OAuth（Google）首次登入以已驗證 Email 綁定既有帳號；登入頁只顯示 OAuth |
